# WaypointTasks

`core/rules/waypoint_tasks.gd`, extends `RefCounted`

Waypoint tasks (spec S11): the four task passes, and resolving colonization (S17).

Every task is built: transport, colonize, remote mining, merge, scrap (with Ultimate
Recycling and the S24 tech bonus), lay mines, route and default orders (Routes), and transfer.
Patrol acts with movement and battles.

## Constants

- `const RECYCLING_MAX := 65535`: Ultimate Recycling banks at most this many resources per fleet and per planet (S11, fix B40).
- `const CARGO_COLONISTS := 3`
- `const COLONIZER_TAG := "colonizer"`
- `const MINERAL_RETURN := [3, 4]`
- `const SCRAP_RETURN`: Minerals recovered by scrapping (S11 "Scrap"), by planet kind and Ultimate Recycling.
- `const TRANSFERRED_COST_DIVISOR := 4`
- `const DESIGN_SLOTS := 16`
- `const MINING_RATE_MAX := 4000`
- `const FLEET_OBJECT := 32768`: Fill and wait percentages use the capacity capped here; from 65,536 on they divide first. A fleet as the "where" of a transport message: this plus the fleet's parameter value (S21).
- `const SPACE_OBJECT := 65534`: The first half of a transport message's "where" for a packet or salvage pile (65534, S21).
- `const LOAD_ACTIONS := ["load_all", "load", "fill_percent", "wait_percent"]`: Transport actions that load (S21 "load refused").
- `const PERCENT_CAPACITY_MAX := 2000000`
- `const PERCENT_SPLIT := 65536`

## Variables

- `var owned_at_start := {}`: Planet id -> true for the planets that had an owner when the task pass began (`DoWaypointTasks` marks them before the waypoint 1 pass's battles): colonists unloaded onto one that has lost its owner since still land (S11 "Unloading").
