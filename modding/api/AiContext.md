# AiContext

`core/ai/ai_context.gd`, extends `RefCounted`

What a computer player works from (spec S22 "The AI step"): its view of the game, the content,
the random stream it draws from, its personality and difficulty level. It gives the turn's
orders through `order`; they are checked and applied like a human player's (S11).

## Variables

- `var view: PlayerView`
- `var content: ContentRegistry`
- `var rng: StarsRandom`
- `var personality: Dictionary`: The personality's content definition (`ai_personality`).
- `var level: int`: Difficulty, 0 (easiest) to ComputerPlayers.LEVELS.size() - 1.
- `var declared := {}`: The brain's declared settings by key (AiBrains.settings), for their defaults.
- `var orders: OrderSet`
- `var shared := {}`: State the computer players of one turn share, as the original's host run carries it from one computer player to the next (ComputerPlayers.add_orders gives them all the same dictionary).
