# GameState

`core/model/game_state.gd`, extends [`ModelObject`](ModelObject.md)

The whole state of one game (spec S03): everything a turn reads and writes.

Collections are lists in the S03 order and are kept that way: players by index, planets by id,
fleets and space objects by (owner, number). Create fleets and space objects with the add_*
functions, which apply the original's "lowest free number" rule. The original's combined order
of all space objects is minefields, then packets and salvage, then wormholes, then traders.

## Constants

- `const FIRST_YEAR := 2400`: Year shown to players for turn 0.

## Variables

- `var turn: int = 0`
- `var settings: GameSettings = GameSettings.new()`
- `var players: Array[Player] = []`
- `var planets: Array[Planet] = []`
- `var fleets: Array[Fleet] = []`
- `var minefields: Array[Minefield] = []`
- `var packets: Array[Packet] = []`
- `var wormholes: Array[Wormhole] = []`
- `var traders: Array[Trader] = []`
- `var rng: RngStreams = RngStreams.new(0)`: The random streams (S01). Saved under "rng".
- `var messages: Array = []`: Per player, this turn's messages (S21).
- `var battles: Array = []`: This turn's battle records (S16).
- `var views: Array = []`: Each player's view of the turn (S15): what the player's scanners saw of the other players. One dictionary per player, or empty when not known (fixtures without the players' files).
- `var history: Array = []`: The score history (S20 "History"): one entry a turn, {turn, records: per player}.
- `var mod_data: Dictionary = {}`
- `var retired_fleet_numbers: Dictionary = {}`: Turn-only: per owner, the fleets retired this turn and where they were ({number: Vector2i}).
- `var turn_start_tech: Dictionary = {}`: Turn-only: per player index, the tech levels at the start of the turn's generation, which the designs' stored stats were computed with (S11 scrap and colonize values).
- `var recycled: Dictionary = {}`: Turn-only: per planet id, the resources Ultimate Recycling banked there this turn (S11).
- `var dropped_colonists: Array = []`: Turn-only: colonists dropped by hand on planets the player doesn't own, waiting for the turn's first ground combat (S17): {fleet, player, planet, colonists, owned}.
