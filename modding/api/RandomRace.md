# RandomRace

`core/universe/random_race.gd`, extends `RefCounted`

Rolls a race with the "random" setting anew at game creation (spec S06 "Random races"),
drawing from the classic stream in the original's order.

## Constants

- `const TARGET_MAX := 50`: Advantage points left must end up within 0..TARGET_MAX.
- `const MAX_REPAIRS := 251`: Repair attempts before the race falls back to the default race.
- `const LEFTOVER_DRAW := 7`: Leftover-point values are drawn from 0..6; 5 and 6 act as surface minerals.
- `const WIDE := [0, 50, 100]`
- `const IMMUNE := [-1, -1, -1]`
- `const GROWTH_MAX_REPAIR := 15`

## Functions

### `new()`

```gdscript
RandomRace.new(content: ContentRegistry, rng: StarsRandom, default_race: Race = null)
```

`default_race` is the fallback when the repair gives up (null: a new Race, the Humanoid preset).

### `roll()`

```gdscript
func roll(race: Race) -> void
```

Rolls `race` in place. An empty name gets one from the race name list.
