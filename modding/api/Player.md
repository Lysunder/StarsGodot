## Variables

- `var index: int = 0`
- `var race: Race = Race.new()`
- `var ai: String = AI_NONE`: AI personality id, or "" for a human player (S22).
- `var ai_level: int = 0`
- `var ai_personality: Dictionary = {}`: The personality's definition as the game was created with it (S22): {name, brain, params, levels}, so the game plays the same without the content or user file it came from. Empty in games made by the original, and for human players: the content definition of `ai` is used.
- `var active: bool = true`
- `var eliminated: bool = false`: Out of the game: no planets and no ships left (S20).
- `var rank: int = 0`: Rank by score, 1 for the highest (S20); 0 before the first scoring and in a one-player game.
- `var score: Dictionary = {}`: This turn's score record (S20): score, resources, planets, starbases, unarmed, escorts, capitals, tech, rank, met (the victory conditions met), winner. Empty before the first scoring.
- `var homeworld: int = -1`: Homeworld planet id, -1 when none.
- `var tech_levels: Array[int] = [0, 0, 0, 0, 0, 0]`: Per tech field, in field order (energy, weapons, propulsion, construction, electronics, biotech).
- `var research_points: Array[int] = [0, 0, 0, 0, 0, 0]`
- `var research_percent: int = 15`
- `var research_field: int = 0`: Field being researched (0..5).
- `var next_research_field: int = NEXT_FIELD_LOWEST`: A field (0..5), NEXT_FIELD_SAME or NEXT_FIELD_LOWEST.
- `var relations: Array[String] = []`: One entry per player index: "neutral", "friend" or "enemy".
- `var battle_plans: Array = []`: Battle plans (S16).
- `var ship_designs: Array[Design] = []`: Designs, sorted by slot; empty slots are absent.
- `var starbase_designs: Array[Design] = []`
- `var default_queue: Array[QueueItem] = []`: The queue a newly colonized planet starts with (standard items only, at most `constant.limits.default_queue_items`; S09, S11).
- `var default_leftover_to_research: bool = false`: The "contribute only leftover resources to research" setting of a new colony.
- `var production_templates: Array = []`: The player's own production templates besides the default (S09 "Production templates"): up to three of {name, leftover_to_research, queue: [queue item dictionaries]}. They don't change the game; only the player's production window uses them.
- `var message_filters: Array[String] = []`: Message types the player has filtered out (S21 "Filters"), sorted.
- `var trader_parts: Array[String] = []`: Mystery Trader part content ids obtained (S18), sorted.
- `var knowledge: Dictionary = {}`: What this player knows of objects it does not own (S15).
- `var mod_data: Dictionary = {}`
- `var tech_bonus_taken: bool = false`: Turn-only mark: the player already gained tech from scrapping, battle or invasion this turn (S24).
- `var tech_levels_at_start: Array[int] = []`: Turn-only: the tech levels when the turn started. The original keeps each design's cost as computed when the turn was loaded, and battles use it (S16); empty outside turn generation.
