# Fleet

`core/model/fleet.gd`, extends [`ModelObject`](ModelObject.md)

A fleet (S03). Identity is (owner, number). Cargo is ironium, boranium, germanium, colonists
(kT; 1 kT = 100 colonists) and fuel (mg).

## Variables

- `var owner: int = 0`
- `var number: int = 0`
- `var name: String = ""`: "" = the default name.
- `var x: int = 0`
- `var y: int = 0`
- `var planet: int = -1`: Planet id when in orbit, else -1.
- `var stacks: Array[ShipStack] = []`: Sorted by design slot, at most one stack per design.
- `var cargo: Array[int] = [0, 0, 0, 0, 0]`
- `var battle_plan: int = 0`: Index into the owner's battle plans.
- `var waypoints: Array[Waypoint] = []`: The first is where the fleet is now, the second its next destination.
- `var repeat: bool = false`
- `var mod_data: Dictionary = {}`
- `var did_not_move: bool = false`: Turn-only mark: the fleet didn't move this turn (S12).
- `var following: bool = false`: Turn-only mark: the fleet is following a fleet this turn (S12 "Following a fleet").
- `var claimed: bool = false`: Turn-only mark: a waypoint targets this fleet (S12 "Waypoint targets").
- `var reorganized: bool = false`: Turn-only mark: a ship move or merge order this turn named the fleet (S11); other players' waypoints on it pick their fleet again (S12 "Waypoint targets"). The first task pass clears it.
- `var gated: bool = false`: Turn-only mark: the fleet went through a stargate this turn (S12; no repair, S19).
- `var mine_hit: bool = false`: Turn-only mark: a minefield hit or damaged the fleet this turn (S13; no repair, S19).
- `var fought: bool = false`: Turn-only mark: the fleet was in a battle this turn (S16; no repair, S19).
- `var at_bombing: bool = false`: Turn-only mark: the fleet orbits a planet its owner's fleets there would bomb this turn (`DoBombing@10e8:6e2a`); it sees that planet (S15).
