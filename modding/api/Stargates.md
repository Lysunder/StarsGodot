# Stargates

`core/rules/stargates.gd`, extends `RefCounted`

Stargate travel (spec S12 "Stargates"): a fleet whose next waypoint has warp 11 jumps from a
stargate (or with Jump Gates on every ship) to a planet with a stargate; designs beyond the
gates' limits are damaged or lost.

## Constants

- `const GATE_LOSS_WORD := 65535`: An unlimited gate range counts as this many light years. Ships lost in one jump above this get the "unbelievable" message (S12).
- `const UNLIMITED_RANGE := 8000`
- `const OVER_LIMIT := 5`: A gate takes up to this many times its limits, with damage beyond 1x.
- `const SURVIVAL := 10000`
- `const FACTOR_SCALE := 2500`
- `const ALL_LOST := 100`
- `const LOSS_DIVISOR := 3`
- `const DAMAGE_SCALE := 500`
- `const PERCENT := 100`
- `const NO_X := -1`: A position given where a planet could be: the first word is -1 for a planet (S21 "object").

## Functions

### `jump()`

```gdscript
static func jump(state: GameState, content: ContentRegistry, rng: StarsRandom, fleet: Fleet) -> String
```

Jumps the fleet through the gates to its next waypoint. Returns the fleet's fate: "stayed" (the
jump was refused), "jumped", or "lost" (every ship destroyed; the caller deletes the fleet).
