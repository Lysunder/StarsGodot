# OrderSet

`core/model/order_set.gd`, extends `RefCounted`

One player's orders for one turn (spec S11): a list of orders, each a Dictionary with a
"type" and that type's fields, applied in list order. Order types are defined by OrderRules.

## Variables

- `var player: int = 0`
- `var turn: int = 0`: The turn (year - 2400) the orders were given in; they apply when that turn is generated.
- `var orders: Array[Dictionary] = []`
