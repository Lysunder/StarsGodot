# ModLoader

`core/mod/mod_loader.gd`, extends `RefCounted`

Reads mod manifests, works out the load order, and loads every mod's content into a fresh
ContentRegistry (MODDING.md §2–4).

Load order: `core` first; then every mod after its dependencies and `load_after` mods and before
its `load_before` mods; ties follow the user's order. Cycles, missing dependencies, version
mismatches and conflicts are errors, and no content is loaded when any are found.

Within a mod: content/**/*.json, then patches/**/*.json, then lang/<locale>.json, each in sorted
path order; then a script mod's entry script (`entry` in mod.json): `_mod_init(api)` with a
ModApi. Script mods are trusted code (MODDING.md §12): one loads only when `trusted` holds its
id with the hash of its scripts (script_hash), which the player confirms once per version.

## Constants

- `const API_VERSION := 1`
- `const CORE_ID := ContentRegistry.CORE_MOD_ID`
- `const RESERVED_TEST_IDS: Array[String] = ["harness_compat"]`: Mod ids only test mods may use: a copy of the compat mod anywhere else is refused (D12).
- `const RULESET_SCRIPT := "ruleset.gd"`: A mod's formula script: `build(ruleset)` replaces or adds formulas. Only test mods may have one until script mods arrive with their trust confirmation (M14).

## Variables

- `var game_version: String = "0.1.0"`
- `var allow_test_mods: bool = false`: Only test runs set this; it allows mods that live under res://tests/ (D12).
- `var trusted: Dictionary = {}`: Script mods the player trusts: mod id -> the hash of its scripts (script_hash).

## Functions

### `load_mods()`

```gdscript
func load_mods(sources: Array[ModSource], enabled: PackedStringArray) -> LoadResult
```

Loads `core` plus the `enabled` mods (in the user's order) from the given sources.

### `script_hash()`

```gdscript
static func script_hash(source: ModSource) -> String
```

The SHA-256 of a mod's scripts (every .gd file, path and text, in path order): what the player
trusts.
