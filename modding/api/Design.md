# Design

`core/model/design.gd`, extends [`ModelObject`](ModelObject.md)

A ship or starbase design (spec S03). Derived values (mass, cost, armor ...) are computed from
content and tech level (S04), never stored.

## Variables

- `var slot: int = 0`
- `var name: String = ""`
- `var hull: String = ""`: Hull content id.
- `var parts: Array[DesignSlot] = []`: One entry per hull slot, in the hull's slot order.
- `var turn_designed: int = 0`
- `var built: int = 0`: Ships of this design ever built, and still existing.
- `var remaining: int = 0`
- `var picture: int = 0`: Cosmetic picture index.
- `var transferred: bool = false`: Came with ships another player transferred (S11); its ships count at a quarter of their cost when scrapped or colonizing.
- `var mod_data: Dictionary = {}`
- `var revealed_to: Dictionary = {}`: Turn-only mark: players who saw this design in full this turn (S15; a minefield hit, a caught packet); keys are player indices.
