# Packet

`core/model/packet.gd`, extends [`ModelObject`](ModelObject.md)

A mineral packet or a pile of salvage (S03, S14). They share one kind and one numbering in
the original; salvage has no destination and warp 0.

## Constants

- `const DECAY_CLASSES := 4`: Decay classes: none, 10%, 25%, 50% a year.

- `var salvage: bool = false`

- `var warp: int = 0`: The packet's speed (5..13); 0 for salvage.
