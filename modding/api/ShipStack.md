# ShipStack

`core/model/ship_stack.gd`, extends [`ModelObject`](ModelObject.md)

The ships of one design in a fleet (S03).

Damage uses the original's form: damaged_percent of the ships are damaged, each by
damage / 500 of the design's armor.

## Variables

- `var design: int = 0`
- `var count: int = 0`
- `var damaged_percent: int = 0`: 0..100.
- `var damage: int = 0`: 0..499, in 1/500 of the design's armor.
- `var paid: Array[int] = [0, 0, 0, 0]`: Ironium, boranium, germanium and resources actually paid for these ships (B14 fix, S11).
