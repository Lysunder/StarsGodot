# Retargeting

`core/visibility/retargeting.gd`, extends `RefCounted`

Orders changed by sight (spec S15 "Orders changed by sight"; `WriteGameFile@1068:35b0`): right
after a player's scanning, patrolling fleets pick a target, and waypoints aimed at what the
player no longer sees lose their target. Fleets seen only in a battle don't count: the original
marks them when it writes the battle blocks, after this.

## Constants

- `const WARP_MAX := 10`

The player `p`'s fleets, in fleet order; `sight` is the player's scanning pass.

### `default_warp()`

```gdscript
static func default_warp(fleet: Fleet, owner: Player, content: ContentRegistry, ease: bool = true) -> int
```

The fleet's default warp (`Fleet_CalcWarp@1048:678c`): the fastest speed every engine runs
below 121 per mille fuel use, eased down to a nearby free speed unless `ease` is false; 0 when
a design has no engine.
