# GameContext

`core/context/game_context.gd`, extends `RefCounted`

Everything one game needs to run its rules: content, ruleset, RNG streams and hooks.

Code in core/ never reaches for globals or autoloads. It receives a GameContext (or a narrower
context built from one) as an argument. That lets several games live in one process: AI
lookahead, parallel tests and harness runs.

The members are placeholders until the systems behind them exist:
content (M2), ruleset (M2/M6), hooks (M6).

## Variables

- `var content: RefCounted = null`: Frozen ContentRegistry for this game (M2).
- `var ruleset: RefCounted = null`: Ruleset holding the formula providers selected for this game (M2/M6).
- `var rng_streams: RngStreams`: Named RNG streams ("classic", "fixes", one per mod) derived from the game seed (S01).
- `var hooks: RefCounted = null`: Hook bus for mod and trait scripts (M6).
- `var game_seed: int = 0`: Seed the game was created with. Every RNG stream is derived from it.
