# TurnContext

`core/turn/turn_context.gd`, extends `RefCounted`

What the phases of one turn work on: the game state, the content, and per-turn values that
pass between phases.

## Variables

- `var state: GameState`
- `var content: ContentRegistry`
- `var research_spent: Array[int] = []`: Resources each player put into research this year (production, S09; spent by the tech update, S05).
- `var orders: Array[OrderSet] = []`: The players' orders for this turn (S11).
- `var rejected_orders := PackedStringArray()`: Orders rejected by the order phase, one line each (messages: S21).
