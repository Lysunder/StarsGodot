# Ways to play

## Against the computer

Choose **New Game...** in the main menu. Pick the size of the galaxy and how many computer players to face, and how
hard they play. **Advanced Game** lets you set every option: density, starting positions, victory conditions, each
computer player's personality and difficulty, and other human players.

## Hotseat

Several people take turns at one computer. Add human players in **Advanced Game**. When one player's orders are in,
a cover hides the screen until the next player is ready, so nobody sees another's turn. The year is generated when
everyone has finished.

## Play by email

One person hosts the game and generates the turns; the others play from **turn files**.

- The host creates the game with the host tool and sends each player their turn file.
- Each player opens their turn file from the main menu (**Open Turn File**), gives orders and submits them, which
  writes an orders file to send back to the host.
- The host generates the next year once the orders are in, and sends out the new turn files.

A turn file holds only what that player knows; it can't be used to peek at others.

## Saving

**File > Save** ({key:save}) saves the whole game, including its computer players, so you can stop and carry on
later from **Open Game** in the main menu.
