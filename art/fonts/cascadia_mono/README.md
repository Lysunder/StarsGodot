# Cascadia Mono

One of the Classic 95 theme's selectable UI fonts (decision D15; View > Font).

- **Font:** Cascadia Mono Regular (static build), from Cascadia Code release v2407.24 by Microsoft.
- **Source:** https://github.com/microsoft/cascadia-code/releases/tag/v2407.24 (file `CascadiaCode-2407.24.zip`,
  downloaded 2026-10-05); only `ttf/static/CascadiaMono-Regular.ttf` is kept.
- **License:** SIL Open Font License 1.1 (`OFL.txt`, the repository's `LICENSE` at that tag). The font keeps its own
  license inside this GPL-3.0 project; a modified version would have to be released under the OFL too.
