# W95FA

One of the Classic 95 theme's selectable UI fonts (decision D15; View > Font).

- **Font:** W95FA Regular, version 1.002, by Alina Sava (FontsArena.com), a modern re-creation of the Windows 95
  interface font.
- **Source:** https://fontsarena.com/w95fa-by-fontsarena/ (file `W95FA.zip`, downloaded 2026-10-04); only the
  OpenType file is kept.
- **License:** SIL Open Font License 1.1 (`OFL.txt`, as shipped in the archive; the font's own name table names the
  author and the license). The font keeps its own license inside this GPL-3.0 project; a modified version of the
  font would have to be released under the OFL too.
