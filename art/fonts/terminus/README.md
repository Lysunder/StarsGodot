# Terminus

One of the Classic 95 theme's selectable UI fonts (decision D15; View > Font).

- **Font:** Terminus (TTF) Regular 4.49.3, Tilman Blumenbach's TrueType conversion of Dimitar Zhekov's Terminus
  Font.
- **Source:** https://files.ax86.net/terminus-ttf/ (file `latest.zip`, downloaded 2026-10-05); only
  `TerminusTTF-4.49.3.ttf` is kept.
- **License:** SIL Open Font License 1.1 (`OFL.txt`, the archive's `COPYING`). The font keeps its own license inside
  this GPL-3.0 project; a modified version would have to be released under the OFL too.
